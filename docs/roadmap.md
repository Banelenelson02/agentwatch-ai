# Master roadmap
Ten flexible stages; dates are not commitments.

- [ ] System design: requirements, HLD, LLD, contracts, ERD and ADRs
- [ ] Python fundamentals: synthetic generator and Ollama telemetry
- [ ] Data transformation: batch ETL, validation and quarantine
- [ ] PostgreSQL and SQL: warehouse and analytical queries
- [ ] Automation: FastAPI, Docker and Airflow
- [ ] Streaming: Kafka producers, consumers and replay
- [ ] Advanced data engineering: Parquet, dbt and quality checks
- [ ] Cloud engineering: AWS integration subject to budget
- [ ] Reliability: failure recovery and benchmarking
- [ ] Portfolio: documentation, dashboard and demonstration

## Release milestones
- v0.1: design baseline, reviewed documentation.
- v1.0: local batch ETL, real/synthetic data and repeatable SQL analytics.
- v2.0: API and scheduled, containerised pipeline.
- v3.0: streaming, replay, Parquet and dbt.
- v4.0: optional temporary AWS integration.
- v5.0: reliability and benchmark report, dashboard and final demo.

Each release needs working code, tests and documentation. Do not claim metrics until measured.
