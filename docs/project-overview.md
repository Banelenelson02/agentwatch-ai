# Project overview

AI applications generate telemetry about latency, tokens, errors, tools and evaluations. Without dependable data pipelines, teams struggle to measure reliability, performance and expenditure.

AgentWatch AI is a data engineering capstone that transforms this telemetry into validated, reproducible analytical datasets. Intended users include data engineers, AI engineers and engineering managers.

Scope: local Ollama telemetry, synthetic workloads, batch and streaming ingestion, data lake, warehouse, data quality, orchestration, dashboards and optional cloud deployment. Out of scope: training LLMs, building a general chatbot, storing private conversations, automated model repair and commercial billing.

Development began with planning on 24 November 2026. The ten-stage roadmap is flexible. Local development targets zero additional service fees, excluding electricity and internet. macOS is the lightweight development environment; Pop!_OS can support heavier tests subject to school permissions and available resources. No cloud resources have been provisioned.
